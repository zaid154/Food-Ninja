## 🌟 Key Features

- 🍕 **Interactive Food Menu**: Browse delicious dishes categorized by cuisine, meal type, and dietary preferences.
- 🛒 **Dynamic Shopping Cart**: Real-time quantity adjustments, price calculations, and persistent cart state.
- 🔍 **Instant Search & Filtering**: Fast item search with live filtering by category, price, and ratings.
- 📦 **Order Lifecycle & Checkout**: Delivery address management, order summary, and order status updates.
- 📱 **Mobile-First Responsive Layout**: Crafted for a seamless ordering experience on mobile devices, tablets, and desktops.

| Layer | Technologies Used |
